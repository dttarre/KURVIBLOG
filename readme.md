# KurviBlog

## Descripción del proyecto

KurviBlog es un blog de motociclismo desarrollado como proyecto académico de la asignatura Desarrollo de Aplicaciones en Red del Grado en Ingeniería Informática de la Universidad Internacional de La Rioja (UNIR).

El objetivo es crear una página web estática que permita aprender la creación de páginas web y de paso 
compartir experiencias moteras.

## Tecnologías utilizadas

- **HTML5:** estructura y contenido de las páginas.
- **CSS3:** diseño visual y adaptación a diferentes tamaños de pantalla.
- **JavaScript:** filtrado dinámico de publicaciones por categorías.
- **Visual Studio Code:** entorno de desarrollo.

## Funcionalidades

- Página principal con tres publicaciones.
- Navegación entre páginas.
- Diseño responsive.
- Filtrado de publicaciones por categorías.
- Resaltado de la categoría seleccionada.
- Sección de presentación del autor.

## Ejecución del proyecto

Para visualizar el blog en local, basta con abrir el archivo `index.html` en un navegador web.

No requiere instalar dependencias ni configurar un servidor.

## Uso de inteligencia artificial

Se ha utilizado IA como herramienta de apoyo al aprendizaje, explicación de conceptos, resolución de errores y generación de material gráfico.

## Finalidad

Proyecto desarrollado con fines académicos.
